# lom-video

Videopresentasjoner til LØM-appen (Teknisk kommunikasjon og ledelse, Fagskolen Oslo, Avdeling Elkraft). Filene publiseres med GitHub Pages på https://truthseeker1968.github.io/lom-video/ og strømmes fra appen (https://truthseeker1968.github.io/lom-app/#/video).

Hver video er 720p med plakatbilde (`<kap>_video<n>.mp4` og `.jpg`). Fortellerstemmen er Glenns egen, klonet i ElevenLabs. Videoene oppsummerer hovedpoengene i kapitlet og erstatter ikke lærebøkene: Hjertnes og Skorpen, «Økonomistyring for LØM-emnet», og Hjertnes, «Markedsføring, organisasjon og ledelse for LØM-emnet». Nordlys Elektro AS er en tenkt casebedrift.

Originaler i 1080p, tekstfiler (.srt) og manus ligger i Gbrain under `Klassemateriell/LOM_Video/`. Ny video: legg mp4 og jpg her, push med oppdraget `video.json` i `LOM_App/_auto/inn/`, og legg en linje i `LOM_App/kilde/innhold/00_video.js`.
